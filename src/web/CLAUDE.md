# CLAUDE.md — src/web/

로컬 읽기 전용 뷰어. 세션이 어디서 끊겼는지 보여준다.

## 이 스코프의 책임

- 조각(세그먼트) 타임라인 시각화
- 조각 내부 대화 열람 (가상 스크롤 + 본문 지연 로딩)
- 절단 지점마다 **복사 가능한 CLI 명령어** 표시

## 이 스코프가 하지 않는 것

- **파일 쓰기.** 쓰기 API를 갖지 않는다 ([ADR-0003](../../docs/adr/ADR-0003-cli-writes-web-reads.md))
- **JSONL 직접 파싱.** 반드시 `src/core/`를 경유한다 — CLI와 답이 갈리면 안 된다
- 외부 바인딩. 서버는 `localhost`(`127.0.0.1`)에만 바인딩한다

## 왜 읽기 전용인가

세션 파일에는 자격증명과 개인정보가 들어 있다. 이 파일을 수정할 권한을 브라우저에서 도달 가능한 경로에 두지 않는다.

수술 대상을 웹에서 CLI로 옮기는 매개는 **클립보드**다. 중간 파일 포맷을 두지 않는다.

## 렌더링 제약

노드 수는 적고(실측: 10,726개) 본문은 크다(수백 MB). 이 비대칭이 설계를 결정한다:

- **본문을 통째로 보내지 않는다.** 서버가 인덱스를 상주시키고, 화면에 보이는 노드의 본문만 바이트 범위로 응답한다
- 조각 타임라인은 기본 접힌 상태 — 초기 렌더는 조각 수(수십 개)만큼이다
- 조각을 펼치면 가상 스크롤. 화면에 보이는 것만 DOM에 올린다
- 시간 순서가 있는 체인이므로 **세로 타임라인 고정 배치**를 쓴다. force-directed 레이아웃은 순서를 뭉개므로 쓰지 않는다

기존 도구들이 대형 세션에서 느린 이유는 파일이 커서가 아니라 전체를 파싱해 문자열로 메모리에 올려 렌더하기 때문이다. 같은 실수를 반복하지 않는다.

## 표시 규칙

- 끊긴 지점을 시각적으로 구분하되, **끊김이 곧 오류라고 단정하지 않는다.** 컴팩트 경계는 정상 동작의 결과다
- 도구가 판단하지 못한 케이스(정책이 없는 중복 등)를 숨기지 않고 표시한다
