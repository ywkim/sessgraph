# PRD: 끊긴 대화 조각을 다시 잇기

## Why (목표)

대화가 끊긴 지점을 확인했다면(끊긴 지점 확인 기능 참고), 다음으로 사용자가 원하는 건 "그 대화를 다시 이어서 쓸 수 있게 만드는 것"이다. 지금은 확인만 할 수 있고, 실제로 잇는 방법이 없다.

직접 파일을 손으로 고쳐서 이으려는 시도는 위험하다. 잘못 건드리면 대화 내용 자체가 사라지거나, 이어붙인 것처럼 보이지만 실제로는 예전 내용을 전혀 기억하지 못하는 상태가 될 수 있다. 사용자는 안전하게, 그리고 무엇을 왜 바꿨는지 나중에 확인할 수 있는 방식으로 이 작업을 하고 싶어한다.

## What / Success Criteria (요구사항 & 성공 기준)

- 사용자가 끊긴 지점 하나를 골라, 그 앞의 대화 조각에 다시 이을 수 있다
- 작업 전에 무엇이 바뀔지 미리 볼 수 있다 (실제로 적용하기 전에 확인 가능)
- 작업은 원본을 안전하게 보관한 채로 이뤄져, 마음에 들지 않으면 되돌릴 수 있다
- 무엇을 왜 이었는지 이유를 함께 남길 수 있어, 나중에 왜 그렇게 했는지 다시 찾아볼 수 있다
- 성공 기준: 이은 뒤 실제로 대화를 이어서 재개했을 때, 이전 내용을 실제로 기억하고 있어야 한다 — 단순히 "연결된 것처럼 보이는 것"만으로는 성공이라 할 수 없다

## Non-Goals (명시적 범위 제외)

- 여러 지점을 한 번에 자동으로 모두 잇는 기능은 포함하지 않는다 (사용자가 지점을 하나씩 고르는 것을 기본으로 한다)
- 이은 뒤 실제로 예전 내용을 기억하는지 자동으로 검증하는 기능은 포함하지 않는다 — 이는 사람이 직접 확인해야 하는 영역이다
- 대화 내용 자체를 요약·편집하는 기능은 포함하지 않는다
