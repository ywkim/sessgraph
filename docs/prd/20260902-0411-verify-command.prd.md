# PRD: 이었던 결과가 실제로 남아있는지 확인

## Why (목표)

끊긴 대화 조각을 이은 뒤에도, 사용자는 "정말로 이어졌는가"를 다시 확인하고 싶어한다. 대화를 다시 이어가려고 시도해보기 전까지는 확신할 수 없는데, 매번 그렇게 시도하는 것은 번거롭다.

또한 시간이 지나 기록이 다시 쌓이거나, 다른 조치를 취한 뒤에도 이전에 이었던 결과가 여전히 유지되고 있는지 궁금할 때가 있다. 사용자는 대화를 실제로 재개하지 않고도 "지금 이 기록이 얼마나 멀리까지 연결되어 있는가"를 빠르게 확인할 방법이 필요하다.

## What / Success Criteria (요구사항 & 성공 기준)

- 사용자가 특정 대화 지점을 지정하면, 거기서부터 거슬러 올라갔을 때 몇 개의 조각까지 연결되어 있는지 확인할 수 있다
- 이전에 이었던 지점이 있다면, 그 연결이 지금도 유지되고 있는지 확인할 수 있다
- 되돌리기 작업을 한 뒤에도, 원래 상태로 정확히 돌아갔는지 같은 방식으로 확인할 수 있다 (되돌리기 확인에도 이 기능을 그대로 쓴다)
- 성공 기준: 대형 기록에서도 몇 초 안에 확인 가능하며, 잇기 작업이 계산한 결과와 이 확인 결과가 항상 일치해야 한다 (같은 계산을 두 번 따로 하지 않는다)

## Non-Goals (명시적 범위 제외)

- 실제로 대화를 재개했을 때 이전 내용을 정말로 기억하는지는 이 기능으로 확인할 수 없다 — 그건 사람이 직접 재개해서 확인해야 하는 영역이다 (연결 여부와 기억 여부는 다른 질문이다)
- 여러 기록을 한 번에 비교하는 기능은 포함하지 않는다
- 연결 상태를 자동으로 고치는 기능은 포함하지 않는다 (그건 잇기 기능의 역할이다)
